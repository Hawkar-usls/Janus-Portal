# 🌍 JANUS PORTAL

**Автоматическая 360°-экспедиция по миру.** Игровой скринсейвер JANUS: персонаж осматривается в реальной панораме, затем прыгает к ещё не посещённой ближайшей доступной точке. Если подходящих точек нет в пределах выбранного радиуса, поиск **автоматически расширяется**.

> **Статус:** опубликован экспериментальный веб-MVP: **https://hawkar-usls.github.io/Janus-Portal/**. Реальный Panoramax и R2 движок естественного взгляда проверены в Edge; GitHub Actions unit PASS. Вход пользователя, серверные J Coins, Google live E2E и вкладка на основном сайте ещё требуют интеграции. Не выдавайте локальные посещения за оплаченные.

## Функции

- **Начальный радиус 5 км:** последовательность **5 → 10 → 20 → 40 → 80 → … → 20 000 км** при отсутствии нового результата.
- Выбор стартового города или координат; ручной прыжок.
- **Panoramax:** открытые панорамы 360°, поиск через официальный STAC API, просмотр через официальный web-viewer, сохранение локальной истории.
- **Google Street View:** подключение через официальный Maps JavaScript API с отдельным **ограниченным браузерным ключом**; запросы и загрузка могут тарифицироваться. Google-derived геоданные остаются **только в текущей сессии** до проверки политики хранения.
- Время на осмотр 2–30 секунд; переключатель **турбо ×2**; пауза/продолжение/остановка.
- Фильтрация по ID источника **и по близости координат** (~20 м), чтобы не открывать одно место многократно.
- Счётчики уникальных посещений, успешных прыжков и суммарного расстояния по прямой; карта на Leaflet/OpenStreetMap для Panoramax-истории.
- Экспорт JSON, локальные достижения. **JC всегда «—» до серверного подтверждения; локальный клиент не может чеканить монеты.**

## R4 — Экстремальный туризм: отдалённые сёла и необычные ландшафты

Теперь в каталоге **70** стартовых направлений (из них **33** удалённых) и **19** экскурсий (из них **7** в категории **«🏕️ Экстремальный туризм»**). Например, высокогорные сёла Индии (Читкул, Спити, Туртук), деревни у Сахары, удалённые районы Намибии, сельские маршруты Танзании и Уганды, Гималаи Непала, Патагония и Лофотены.

Во вкладках **«Экскурсии»** и **«Места мира»** выбирай категорию **«🏕️ Экстремальный туризм»**, затем регион **Индия / Африка / Другая Азия / Другие**. В обычном **Свободном портале** случайный старт теперь включает удалённые локации; отдельные пункты **«Случайный экстрим»**, **«Случайная Индия»**, **«Случайная Африка»** выбирают соответствующие географические начала.

Эти маршруты действительно используют **поиск доступных панорам**, а не набор придуманных кадров. Наличие названия села в каталоге **не гарантирует** 360° изображение: Panoramax имеет неравномерное покрытие, а Google требует официального Maps API-ключа. На Рейне (Норвегия) настоящий Panoramax 360° снимок был проверен в Edge; для ряда сельских мест Индии и Африки подходящие 360° изображения в первых выборках не найдены. В экскурсиях такие остановки пропускаются без начисления JC; в свободном Портале по-прежнему работает адаптивный радиус 5 → 10 → 20 км и далее.

Название «экстремальный» относится к географии и необычности путешествия, **не к людям, национальности или уровню жизни**. Подробности: [docs/EXTREME_RURAL_R4.md](docs/EXTREME_RURAL_R4.md).

## R3 — полный экран и экскурсии по достопримечательностям

**Режим в духе Discovery Flights:** три вкладки — **«Свободный портал»**, **«Экскурсии»**, **«Места мира»**. Выбирай из **37 направлений** или **12 тематических маршрутов** (Древний Египет: Гиза, Каир, Луксор; Париж; Рим; Токио; Лондон; Нью-Йорк; Стамбул; чудеса света и природа). Путь экскурсии показан на карте; остановки автоматически сменяются после осмотра живым взглядом.

На панели панорамы есть **⛶ На весь экран**: второй щелчок или **Esc** возвращает обычный вид. На мобильных браузерах без Fullscreen API предусмотрен запасной иммерсивный режим.

**Честная доступность:** каждая туристическая остановка означает поиск реальной 360° панорамы поблизости (обычно не далее 4 км), а не обещание снимка точно у монумента. Если источник не нашёл новых подходящих изображений, остановка пропускается. В свободном режиме остаётся обычное расширение 5 → 10 → 20 км и далее. Google Street View требует отдельный ограниченный браузерный ключ; J Coins по-прежнему не начисляются.

Технические детали, тесты и ограничения: [R3 Discovery Tours](docs/DISCOVERY_TOURS_R3.md).

## R2 — живой взгляд, а не механическое вращение

После загрузки панорамы самостоятельный `GazeDirector` плавно поворачивает камеру, оглядывается, ненадолго замирает, возвращается к увиденным деталям, выполняет плавный зум («прищуривание»), потом возвращает широкий обзор. Длительность **случайна для каждой точки** и увеличивается с количеством/оценкой интересных деталей. Настройки: естественный/мягкий/статичный осмотр, анализ контраста/локальная ML/без анализа, базовое время 5–60 секунд, турбо ×2.

**Panoramax:** изображение (в памяти браузера) используется для оценки контраста и, если пользователь выбрал режим, для локальной MediaPipe EfficientDet-Lite0 детекции объектов, включая `person`. Результат вероятностный, не гарантирует точного наведения на объект или обнаружения всех людей. Никакой идентификации людей. Библиотека и веса модели загружаются из CDN; поставщик MediaPipe может собирать технические метрики использования. Фото не отправляются в JANUS.

**Google Street View:** только движение официальной камеры, **без** извлечения пикселей, классификации людей, скачивания снимков или наложения Google-координат на OSM.

Для локального браузерного smoke-теста можно использовать `tools/browser-gaze-check.mjs` (требует установленный Playwright и отдельный работающий `npm run dev`). Подробности: [docs/HUMAN_GAZE_R2.md](docs/HUMAN_GAZE_R2.md). **Browser PASS Panoramax ≠ Google browser PASS**.

## Быстрый старт

Требуется Node.js 20+:

```bash
git clone https://github.com/Hawkar-usls/Janus-Portal.git
cd Janus-Portal
npm run verify
npm run dev
```

Откройте **http://127.0.0.1:4173**. Используйте локальный HTTP-сервер, не открывайте `index.html` как `file://`: ES modules и браузерные API могут блокироваться.

**Без Node:** любой статический HTTP-сервер, обслуживающий `index.html` и `src/`.

### Google-режим

Google Maps JavaScript API со Street View нужно включить в Google Cloud, настроить биллинг, ограничение ключа по **HTTP referrers** для вашего конкретного домена и **API restrictions**, а также бюджет/квоты. Ключ в репозиторий, README, issue, Actions лог или историю коммитов **не вставлять**. Для локальной разработки нужен отдельный ограниченный ключ. При подозрении на утечку — ротировать.

Ключ вводится во время запуска в интерфейсе и не пишется в localStorage. В Google-режиме панорама показывается официальным виджетом с его атрибуцией; содержимое Street View не скачивается и не перепубликуется. Сведения Google о местах сохраняются только в памяти текущей вкладки; в карту OSM попадают только Panoramax-данные. Перед постоянным хранением и объединением с глобальным рейтингом — проверить актуальные Google Maps Platform Terms.

### Публикация GitHub Pages

Workflow `.github/workflows/pages.yml` публикует **только** `index.html` и нужные `src/*` после push в `main`. **Pages включён и использует GitHub Actions.** Проверенная публикация R2: [JANUS PORTAL](https://hawkar-usls.github.io/Janus-Portal/), workflow [45012393984](https://github.com/Hawkar-usls/Janus-Portal/actions/runs/45012393984) PASS после добавления всех JS-модулей и задержки для индексации артефакта. После следующих изменений подтверждайте состояние нового workflow; успешный предыдущий run не гарантирует успешность следующего.

## Как выбирается следующее место

1. Ищем новые панорамы **в радиусе 5 км** (или выбранном пользователем).
2. Отбрасываем уже открытые ID, координаты ближе 20 м к ранее посещённым и варианты вне радиуса.
3. Случайно выбираем одну из ближайших допустимых точек (из пула до 6).
4. Если подходящих результатов нет, расширяем радиус ×2 и повторяем. После достижения 20 000 км или ошибки API — честно сообщаем об ограничении, **не заявляем, что все панорамы Земли исчерпаны**.
5. Записываем посещение **только после успешной загрузки панорамы**. Пока нет backend — в локальную историю, без начисления JC.

Поиск использует ограниченные выборки источников: это **вероятностная разведка**, не исчерпывающий перебор всех панорам. В редких случаях 360° изображение может не загрузиться: оно не должно давать монет и не считается успешным открытием. При изменении или прекращении работы внешних API повторите браузерный smoke-test.
