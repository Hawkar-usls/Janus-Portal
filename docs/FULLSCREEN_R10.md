# R10 — полноэкранный режим исходного окна JANUS

**Дата:** 22 ноября 2026. **Статус на момент подготовки:** локальные 39/39 и Edge desktop/mobile PASS; релизный PR и Pages проверяются отдельно.

## Требование

Владелец потребовал «нам так же необходим режим на весь экран» сразу после утверждения строгого R9 — все панорамы и состояния должны оставаться внутри единственного исходного окна JANUS, без отдельного шлюза и внешних экскурсий.

## Реализация

- `index.html`: одна кнопка `#fullscreenBtn` непосредственно в верхней панели оригинального `.viewer-panel` рядом с индикатором запуска. Подпись меняется между **«⛶ На весь экран»** и **«⛶ Свернуть»**, `aria-pressed`, `aria-label` и `title` синхронизируются.
- `src/app.js`: существующий R2 модуль, **без новых импортов**. Использует `Element.requestFullscreen()` и `document.exitFullscreen()`, слушает `fullscreenchange`. Если браузер запрещает Fullscreen API или оно недоступно, CSS-класс `portal-fullscreen-fallback` растягивает `.viewer-panel` до всего viewport (`100dvh`); кнопка и **Esc** закрывают fallback. Тело блокирует фоновый скролл только в fallback; при выходе разблокирует. `resize` помогает исходному плееру обновить размеры.
- `src/styles.css`: исходное окно просмотра становится flex-контейнером на всю высоту; **`#viewer` растягивается** и показывает ту же панораму. Панель состояния, кнопка выхода, координаты и сообщение остаются в интерфейсе. Компактные стили для телефонов.
- Никакой дополнительной web-панорамы, iframe, внешнего перехода, копирования медиа или API-запросов. Старая кнопка «Запустить» и поиск R9 — единственный способ выбрать и открыть место.
- Полноэкранный режим доступен и до первой панорамы (показывает исходный экран ожидания), и при обычном движении камеры. В browsers с разрешённым HTML Fullscreen API скрывается сама обычная рамка сайта, а в мобильном fallback может оставаться адресная строка браузера.

## Воспроизводимая проверка

- `npm run verify`: **39/39 PASS**, три новых офлайн-теста проверяют кнопку, API, Esc/mobile fallback, отсутствие шестого импорта/второго просмотрщика.
- `tools/browser-fullscreen-r10-check.mjs`: Edge/Playwright на Yaksa:
  1. Запустить **реальную** Panoramax 360° панораму Феса с живым взглядом через старую R2 кнопку. Перейти в нативный fullscreen `document.fullscreenElement===.viewer-panel`; фотография не теряется, в тестовом viewport 1366×840 высота панорамы была **644px**. Кнопка «Свернуть» возвращает обычную страницу, не удаляя `pnx-photo-viewer`.
  2. Искусственно отключить `requestFullscreen`: CSS fallback заполняет всю область браузера, Esc возвращает обычный вид, повторная кнопка входит/выходит.
  3. Телефон 390×844: fallback заполняет высоту **844px**, для самой панорамы доступно **703px**, кнопка выхода видима. **0 uncaught page errors**.

## Приёмочные условия и ограничения

После CI надо дождаться Pages, повторить этот тест на **публичном HTTPS**, убедиться в сохранности `./src/app.js` и пяти R2 import, затем попросить владельца подтвердить, что его браузер по-прежнему работает. Поскольку в прошлом версии R3–R5 потеряли загрузку JS у владельца, не вводить новые библиотеки и не переиспользовать устаревший `src/fullscreen.js` из архива. Полноэкранный режим не улучшает покрытие КНДР/Каира: если легальных 360° нет, в том же окне будет сообщение об отсутствии.

Будущие расширения — только в том же поиске и с лицензированными источниками.
