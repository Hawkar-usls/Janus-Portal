# JANUS PORTAL R13 — единый автоматический миксер 360°-источников

**Дата:** 2026-11-22. **Запрос владельца:** «я не вижу смысла выбирать источники, пусть все перемешиваются по локациям, берем все что есть, а так же обновляюстя пусть разом».

## Что изменилось

Теперь **вообще нет видимого селектора провайдеров**. Пользователь видит только старые «Откуда начинаем» → «▶ Запустить» и «⟳ Обновить». Один запуск обновления одновременно проверяет три **реально доступных публичных источника** для известных географических точек: Panoramax, KartaView, Wikimedia Commons. Внутреннее `<select id="provider" hidden>` оставлено только ради совместимости старого DOM — пользователю не предлагается выбирать источник.

Каждый из **39 известных стартовых районов** появляется в видимом списке лишь если хотя бы один API прямо сейчас вернул подходящий 360° объект. Статус показывает число доступных районов **по каждому источнику**, но один географический район с несколькими источниками считается **одним вариантом списка**. Внутри района результаты разных источников сохраняются как список реальных кандидатов; JANUS выбирает наименее посещённый источник, а при совпадении — ближайшую панораму. Уникальность визитов — по source ID и пространственному порогу; никаких клиентских J Coins.

Одна кнопка «⟳ Обновить» инициирует всю проверку заново с общим поколением `AbortController`: отменяет старый поиск, очищает прежние ответы, постепенно заполняет список и никогда не возвращает устаревшие ответы из предыдущей попытки. Плановая периодичность **5 минут в простое**, общий предел **30 секунд** для сетевых ошибок/долгих источников, максимум 4 одновременные географические очереди. Отдельные недоступные API не могут скрыть результаты других.

## Источники и ограничения прав

| Источник | API / подтверждение 360° | Где фотография показывается | Ограничения |
|---|---|---|---|
| **Panoramax** | Федеративный STAC, equirectangular/FOV≥300 с source ID и image asset | Старый официальный Panoramax R2 viewer | Как раньше, сохраняются фотографические кредиты; покрытие не глобальное |
| **KartaView** | `api.kartaview.org/2.0/photo` с `lat/lng/radius=500/projection=SPHERE`; строго `fieldOfView≥300`, валидная координата и CDN `imageProcUrl` | В нашем окне в лёгком оригинальном WebGL сферическом плеере, лицензия CC BY-SA 4.0 и ссылка на фото | Не выдавать плоские фото за 360°, не обращаться к медленному storage напрямую; если CDN/CORS недоступен, фото не засчитывать |
| **Wikimedia Commons** | Официальный `action=query&generator=geosearch`, CORS `origin=*`; проверка 2:1, категорий/описания equirectangular, авторства, лицензии CC/PD, координат и разрешённого thumb URL | Тот же WebGL сферический плеер с автором, лицензией и прямой ссылкой на Commons | Случайные 2:1 кадры **не** считаются сферическими; Commons может вернуть `cirrussearch-too-busy`; тогда результаты этого API временно отсутствуют |
| **Google Street View** | Официальный Maps JavaScript API | Только по явному ручному запросу со своим разрешённым ключом | **Не входит в массовую автоматическую проверку**: платный API и риск расходования квоты. Для ручного поиска требуется ключ и отдельная галочка согласия, максимум одна серия из 4 платных metadata-запросов |
| **Mapillary** | Официальный Graph API/MapillaryJS | **Пока не включён в готовый миксер** | Нужен собственный токен приложения, разрешения/атрибуция и отдельный реальный browser E2E; нельзя использовать чужой демонстрационный токен |

Источники: https://docs.panoramax.fr/federated-catalog/overview/ , https://kartaview.org/doc/photos , https://commons.wikimedia.org/wiki/Commons:API/MediaWiki , https://help.mapillary.com/hc/en-us/articles/360010234680-Accessing-imagery-and-data-through-the-Mapillary-API .

**Мы не заявляем подключение всех сервисов планеты.** R13 смешивает три подтверждённых бесплатных и открытых источника. Google и Mapillary не могут быть включены автоматически без нужных учётных данных и соблюдения условий. Никаких iframe, подмены чужих снимков, аутсорсинга пользовательских фото, скрейпинга Google или скрытого расходования API.

## Реальный 360° просмотр KV/Commons

`src/providers.js` содержит минимальный WebGL shader/equirectangular renderer без новых runtime-модулей и внешних скриптов. Поверх полотна — атрибуция с исходным URL, автором/правообладателем и лицензией. Поддерживаются drag, колесо мыши, движение/приближение автоматической камерой R2, пауза (не уничтожает WebGL), изменение размера/полный экран. Обязательны **CORS разрешение изображения, HTTPS URL разрешённого домена, настоящее 2:1 разрешение**; при ошибке загрузки фотография не записывается как посещённая, и JANUS пробует другую фотографию в том же географическом районе.

**Найден и исправлен визуальный дефект:** первый WebGL renderer показывал KartaView и Commons вверх ногами из-за флага `UNPACK_FLIP_Y_WEBGL`. После реального браузерного снимка экрана флаг изменён на `false`; скриншоты реального Феса и Сан-Диего проверены визуально — горизонт и изображение правильной ориентации.

Перечисление фотографий KartaView, Wikimedia Commons и Panoramax в `probeMerged360()` основано на реальном source API. Источник не определяет, какой город пользователь может выбрать; выбор только по координатам с валидированными панорамами.

## Тестирование

- `npm run verify`: **55/55 PASS** локально на Yaksa. Пять новых тестов проверяют фильтрацию KartaView FOV/projection/CORS/дистанция; Wikimedia 2:1/категория/licence/GPS; изоляцию ошибок одного сервиса; отсутствие видимого селектора; сохранность пяти исходных R2 модульных путей и R10 fullscreen.
- **Реальный Edge/Playwright:** `tools/browser-merged-r13-check.mjs` открыл test-server версию и завершил общий поиск: **20 подтверждённых географических вариантов**. По источникам: **Panoramax 19**, **KartaView 7**, **Wikimedia Commons 1**. Сумма 27 **не** означает 27 непересекающихся мест, и число 20 может измениться при следующем запросе.
- В Edge **реально загружена** KartaView 360° `2633211980` у Феса (CDN с CORS) и геопривязанная Wikimedia Commons equirectangular фотосфера Сан-Диего (2:1 JPEG, CC BY-SA 4.0). Отдельно проверены WebGL отображение, смена heading/zoom, авторство/ссылка, обратная ориентация изображения, первый пользовательский запуск JANUS, полноэкранный режим и ноль необработанных ошибок JS.
- В мобильном viewport проверены отсутствие селектора источников и доступность единственной кнопки обновления.
- **Честные научные границы:** снимок с валидной GPS-меткой не гарантирует точность самой метки (старый пример аномальной координаты Того). Геотеги Wikimedia и KartaView не являются независимыми геодезическими подтверждениями. Проверяем только 39 заранее известных анкеров, не все места мира.

## Гарантии обратной совместимости

- **Оригинальный `./src/app.js` — ровно пять импортов**: navigation, providers, storage, gaze, attention. В WebGL нет новых библиотек, CDN и loader.
- Старый Panoramax 360 viewer продолжает получать исходные STAC фото; Google не копируется/анализируется.
- Единый поиск R9 и полноэкранный R10, адаптивная география, карта, история, разграничение серверных J Coins и отмена устаревших запросов сохраняются.
- Исходные варианты «случайное место мира» не возвращены.
