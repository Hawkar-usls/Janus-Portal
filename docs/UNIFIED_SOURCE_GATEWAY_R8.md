# JANUS PORTAL R8 — Unified Source Gateway (R2-safe)

**Дата:** 2026-11-22. **Задача:** единый вход к разнородным 360° и 3D источникам (КНДР, Каир/Гиза, Африка, Азия) в самом JANUS без повторения повреждения загрузки R3–R5.

## Реализовано

В основной странице ниже привычного просмотрщика появился блок **«JANUS GATEWAY · ЕДИНОЕ МЕНЮ ИСТОЧНИКОВ»**. Пользователь выбирает географическое место; шлюз показывает четыре возможных канала, но **только те, которые технически и юридически доступны**:

1. **Panoramax — прямо внутри JANUS.** Кнопка переключает уже существующий `originChoice`, выбирает Panoramax и запускает **старую R2** функцию `run()`, автоматически переводя экран к просмотру. Реальные Panoramax снимки внутри JANUS, фотографический кредит в официальном просмотрщике. Статус «проверено ранее» только для 8 действительно протестированных областей (Париж, Фес, Мерзуга, Пуна, Катманду, Себу, Джорджтаун, Куэнка). Покрытие может меняться.
2. **Google Street View — внутри JANUS при наличии разрешённого ключа.** Шлюз использует существующий GoogleProvider и не выполняет запросов без введённого HTTP-referrer/API restricted браузерного ключа. При отсутствии ключа показывает понятное действие, раскрывает поле и переводит фокус, не инициируя платный запрос. Google content лицензируется Google, не копируется, не анализируется локальным детектором.
3. **Специальные экскурсии владельцев контента — из одного каталога.** Для Северной Кореи — DPRK Panorama, для Египта/Гизы — Harvard Digital Giza, Египетское министерство туризма и древностей. Кнопки **«Открыть экскурсию»** открывают разрешённый обычный `<a target="_blank" rel="noopener noreferrer">` в новой вкладке. **Нет** iframe, скрейпинга, рехостинга фото, обмана защитного заголовка CSP/X-Frame-Options или автоматически начисляемых J Coins. Harvard 3D — реконструкция, не фотография центра Каира.
4. **Отсутствующее покрытие — понятная граница.** КНДР и Каир ранее не имели подтверждённых Panoramax 360° в выборках. Шлюз может *проверить район* как на R7 с поиском до 40км без переброски в другую страну; если источник пуст, показывает честный «не найдено» и сохраняет статус посещений.

## Важный контур совместимости

- **Нет новых ES-module import**; `index.html` грузит исключительно `./src/app.js`, у него по-прежнему **5 исходных импортов**.
- Шлюз — дополнительные HTML-секция, CSS и локальные функции в существующем `src/app.js`; не менялись базовый viewer, Panoramax/Google providers, рандомный маршрут, стартовый радиус 5км, анимированный осмотр, запись истории, внешние API или сборка Pages.
- При открытии нового встроенного источника через шлюз работающий режим корректно останавливается через прежнюю `stop()`, затем вызывает `run()`. Классический «▶ Запустить» не менялся.
- Доступные источники — **не автоматический серверный агрегатор контента**. Без лицензии/официального embed/API права мы не можем показывать чужие VR внутри плеера JANUS. Единое меню — первый шаг к универсальному шлюзу; перенести все медиа внутрь без разрешения невозможно.

## Проверки

- **34/34 Node unit PASS**, включая 4 новых теста регрессий шлюза.
- `tools/browser-gateway-check.mjs` на Yaksa/Edge: новая панель/источники КНДР и Гизы PASS; ссылка безопасности rel/target PASS; Google без ключа → поле ключа, **0 платных запросов**; Фес → **настоящая Panoramax 360°** внутри, естественный осмотр PASS; Пхеньян со смоделированным отсутствием снимков → bounded search, посещения не прибавились, кнопка снова «Запустить», **0 uncaught page JS errors**.
- Реальное покрытие Google и встраивание сторонних сайтов **не проверены и не заявляются**.

## Следующий этап архитектуры

Для настоящего универсального контентного шлюза нужны независимые **адаптеры на официальные API/SDK**, паспорт разрешений каждого провайдера (embed allowed, attribution, caching, privacy, geospatial provenance), единая схема кандидата `{provider,id,location,format,license,attribution,viewMode,sourceUrl}`, централизованные лимиты запросов и метрики покрытия, а также UI fallback для запрещённых iframe. **Нельзя** строить прокси, скрывающий происхождение или обходящий запреты встраивания. Кешировать только разрешённые метаданные, не изображения Google. Для платных API и ключей нужен отдельный авторизованный backend и budget guard. Эти задачи не закрыты R8.

## Релизные шлюзы

После PR: main CI, Pages deployment и повторный Edge/Playwright тест **на публичном HTTPS**, затем подтверждение владельцем, что базовая R2 по-прежнему запускается в его браузере. Если его браузер опять показывает пустой экран — срочно откатить R8 и расследовать конкретный модуль, а не возвращать старые R3–R5.
