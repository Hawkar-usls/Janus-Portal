Поиск панорам

⚙
Google Street View · необязательное подключение
Ключ не сохраняется Порталом. Разреши только Maps JavaScript API и адрес этого сайта, настрой квоты и биллинг. Загруженные панорамы остаются в официальном просмотрщике Google. Как получить и ограничить ключ Google ↗ Бесплатный Google Maps Demo Key не поддерживает Street View. Ключ применяется только при явно запущенном ручном поиске; массовое обновление не делает платных Google-запросов.
Обновляем каталог Panoramax по живым данным…
JANUS объединяет Panoramax, KartaView и Wikimedia Commons по координатам без выбора источника. Одна кнопка «Обновить» проверяет все три каталога вместе; непроверенные 2D-фото исключены. Google подключается к ручному поиску только после ввода ключа и согласия. Фото откроется здесь же после проверки загрузки.
📍 Свои координаты · отдельная проверка Поиск по координатам проверяет все бесплатные источники вместе. Если ты ввёл Google-ключ и включил платный поиск, добавится также Google Street View. Неподтверждённые места в общий список не попадают.

Каждая панорама получает разное время: заметные детали, повторные взгляды и приближения увеличивают длительность. Турбо ускоряет всё движение. Распознавание доступно только для открытых Panoramax-панорам. Модель выполняется в браузере и может ошибаться; Google-изображения не анализируются. Личные данные и снимки не отправляются на сервер JANUS.
